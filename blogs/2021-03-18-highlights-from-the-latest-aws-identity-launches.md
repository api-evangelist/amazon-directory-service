<hr /> 
<p>Here is the latest from <a href="https://aws.amazon.com/identity/" rel="noopener noreferrer" target="_blank">AWS Identity</a> from November 2020 through February 2021. The features highlighted in this blog post can help you manage and secure your <a href="http://aws.amazon.com/" rel="noopener noreferrer" target="_blank">Amazon Web Services (AWS)</a> environment. Identity services answer the question of <em>who</em> has <em>access</em> to <em>what</em>. They enable you to securely manage identities, resources, and permissions at scale and to operate your AWS environment more efficiently.</p> 
<p>AWS Identity services include <a href="https://aws.amazon.com/iam/identity-center/" rel="noopener noreferrer" target="_blank">AWS IAM Identity Center</a>, <a href="https://aws.amazon.com/directoryservice/" rel="noopener noreferrer" target="_blank">AWS Directory Service</a>, <a href="https://aws.amazon.com/cognito/" rel="noopener noreferrer" target="_blank">Amazon Cognito</a>, <a href="https://aws.amazon.com/iam/" rel="noopener noreferrer" target="_blank">AWS Identity and Access Management (IAM)</a>, <a href="https://aws.amazon.com/ram/" rel="noopener noreferrer" target="_blank">AWS Resource Access Manager</a>, and <a href="https://aws.amazon.com/organizations/" rel="noopener noreferrer" target="_blank">AWS Organizations</a>. If you’re a security architect, you’ll want to consider the new features related to multi-factor authentication (MFA) and access control that can improve your security posture. If you’re an identity administrator, you might want an easier way to manage identities and their access in AWS. Regardless of your role, you’ll appreciate the visibility and efficiency improvements for centrally managing and governing AWS environments. Let’s review the latest changes and find where you can benefit!</p> 
<h2>Identity management launches</h2> 
<p>The identity management services provided by AWS Identity include <a href="https://aws.amazon.com/iam/identity-center/" rel="noopener noreferrer" target="_blank">AWS IAM Identity Center</a>, <a href="https://aws.amazon.com/directoryservice/" rel="noopener noreferrer" target="_blank">AWS Directory Service</a>, and <a href="https://aws.amazon.com/cognito/" rel="noopener noreferrer" target="_blank">Amazon Cognito</a>. They help you migrate existing workloads to AWS by providing flexible options for where and how you manage your employee, partner, and customer identities. To summarize, the releases discussed in this section provide more options for availability, authentication, and access control.</p> 
<h3>Microsoft Active Directory identities can now be synchronized with AWS IAM Identity Center</h3> 
<p><a href="https://aws.amazon.com/iam/identity-center/" rel="noopener noreferrer" target="_blank">AWS IAM Identity Center</a> lets you centrally manage access to multiple AWS accounts and business applications and provide users with single sign-on access to all their assigned accounts and applications from one place. AWS IAM Identity Center <a href="https://aws.amazon.com/about-aws/whats-new/2020/12/aws-single-sign-on-supports-microsoft-ad-synchronization/" rel="noopener noreferrer" target="_blank">synchronizes users, groups, and group memberships from Active Directory</a> in addition to Azure AD, Okta, Ping Identity, and OneLogin. Now, any changes you make to user and group information in Active Directory is automatically reflected in AWS IAM Identity Center, reducing your administrative effort to manage identities in AWS. AWS IAM Identity Center integrated applications can use the identity data for fine-grained authorization, collaboration, and other in-application user experiences.</p> 
<h3>More options for MFA when using AWS IAM Identity Center</h3> 
<p>AWS IAM Identity Center now can <a href="https://aws.amazon.com/about-aws/whats-new/2020/11/aws-single-sign-on-enables-enforced-mfa-device-enrollment-during-sign-in/" rel="noopener noreferrer" target="_blank">require MFA for new users</a> and <a href="https://aws.amazon.com/about-aws/whats-new/2020/11/aws-single-sign-on-adds-web-authentication-webauthn-support-for-user-authentication-with-security-keys-and-built-in-biometric-authenticators/" rel="noopener noreferrer" target="_blank">use additional factors through WebAuthn support</a>, which enables use of hardware and biometric authenticators such as YubiKeys and fingerprints. This new capability is available when using AWS IAM Identity Center or Microsoft Active Directory as your identity source.</p> 
<h3>AWS Managed Microsoft AD instances are now available across Regions</h3> 
<p>You now can now <a href="https://aws.amazon.com/about-aws/whats-new/2020/11/aws-managed-microsoft-ad-adds-automated-multi-region-replication/" rel="noopener noreferrer" target="_blank">deploy and use a single AWS Managed Microsoft AD (Enterprise Edition) directory across multiple AWS Regions</a>. This change makes it easier and more cost-effective to globally deploy and manage Microsoft Windows and Linux workloads.</p> 
<h3>WorkSpaces now supports smart cards</h3> 
<p>Users can now <a href="https://docs.aws.amazon.com/directoryservice/latest/admin-guide/ad_connector_clientauth.html" rel="noopener noreferrer" target="_blank">authenticate with their smart cards into Amazon WorkSpaces</a> with <a href="https://docs.aws.amazon.com/directoryservice/latest/admin-guide/directory_ad_connector.html" rel="noopener noreferrer" target="_blank">Active Directory Connector</a>. This enables customers who use smart cards—such as US federal agencies—to access <a href="https://aws.amazon.com/workspaces/" rel="noopener noreferrer" target="_blank">WorkSpaces</a> with their cards instead of entering their user name and password. This feature supports <a href="https://aws.amazon.com/blogs/publicsector/amazon-workspaces-supports-cac-piv-smartcard-authentication/" rel="noopener noreferrer" target="_blank">pre-session and in-session authentication</a>. Pre-session authentication is currently available only in the AWS GovCloud (US-West) Region.</p> 
<h3>Amazon Cognito joins AWS IAM Identity Center in supporting ABAC for fine-grained permissions in AWS</h3> 
<p><a href="https://aws.amazon.com/cognito/" rel="noopener noreferrer" target="_blank">Amazon Cognito</a> identity pools <a href="https://aws.amazon.com/about-aws/whats-new/2021/01/amazon-cognito-identity-pools-now-enables-customers-to-use-attributes-from-identity-providers-to-simplify-permissions-management-to-aws-resources/" rel="noopener noreferrer" target="_blank">now enable you to use attributes from social and corporate identity providers</a> to make access control decisions and simplify permissions management to AWS resources. AWS IAM Identity Center also <a href="https://aws.amazon.com/about-aws/whats-new/2020/11/aws-single-sign-on-enables-attribute-based-access-control-simplify-permissions/" rel="noopener noreferrer" target="_blank">recently launched attribute-based access control (ABAC) support</a>, which enables you to create fine-grained permissions through attributes that are defined in your AWS IAM Identity Center identity source, such as cost center and department. Learn more about ABAC from <a href="https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction_attribute-based-access-control.html" rel="noopener noreferrer" target="_blank">What is ABAC for AWS</a>.</p> 
<h2>Access management launches</h2> 
<p><a href="https://aws.amazon.com/iam/" rel="noopener noreferrer" target="_blank">AWS IAM</a> ties your identities to the resources they need access to. IAM provides the granularity to control a user’s access to specific AWS services and resources using permissions, which helps you to enforce least privileged access control. IAM also helps you <a href="https://aws.amazon.com/iam/features/analyze-access/" rel="noopener noreferrer" target="_blank">analyze access</a> across your AWS environment by identifying resources that can be accessed from outside your account.</p> 
<h3>More AWS services and resources now support tags and can be used for ABAC</h3> 
<p>IAM now allows you to <a href="https://aws.amazon.com/about-aws/whats-new/2021/02/aws-identity-and-access-management-now-supports-tags-on-additional-resources/" rel="noopener noreferrer" target="_blank">use tags to manage and secure access to more resources</a>, including customer managed policies, instance profiles, OpenID Connect providers, SAML providers, server certificates, and virtual MFAs. Tags and ABAC are also now supported on <a href="https://aws.amazon.com/about-aws/whats-new/2021/01/amazon-managed-blockchain-supports-resource-tagging-tag-based-access-control/" rel="noopener noreferrer" target="_blank">Amazon Managed Blockchain</a>, <a href="https://aws.amazon.com/about-aws/whats-new/2020/12/service-quotas-now-supports-tagging-and-attribute-based-access-control-abac/" rel="noopener noreferrer" target="_blank">Service Quotas</a>, and <a href="https://aws.amazon.com/about-aws/whats-new/2020/12/attribute-based-access-control-abac-aws-key-management-service/" rel="noopener noreferrer" target="_blank">AWS Key Management Service (AWS KMS)</a>.</p> 
<h3>IAM Access Analyzer now supports more resources that can be inspected for unintended external access</h3> 
<p><a href="https://docs.aws.amazon.com/IAM/latest/UserGuide/what-is-access-analyzer.html" rel="noopener noreferrer" target="_blank">IAM Access Analyzer</a> now <a href="https://aws.amazon.com/about-aws/whats-new/2021/01/discover-review-remediate-unintended-access-secrets-manager-iam-access-analyzer/" rel="noopener noreferrer" target="_blank">analyzes AWS Secrets Manager resource-based policies</a> for public access to secrets. This adds to the <a href="https://docs.aws.amazon.com/IAM/latest/UserGuide/access-analyzer-resources.html" rel="noopener noreferrer" target="_blank">growing list of resources</a> that you can analyze using Access Analyzer, including <a href="http://aws.amazon.com/s3" rel="noopener noreferrer" target="_blank">Amazon Simple Storage Service (Amazon S3)</a> buckets, IAM roles, <a href="http://aws.amazon.com/kms" rel="noopener noreferrer" target="_blank">AWS KMS</a> keys, <a href="http://aws.amazon.com/lambda" rel="noopener noreferrer" target="_blank">AWS Lambda</a> functions and layers, and <a href="http://aws.amazon.com/sqs" rel="noopener noreferrer" target="_blank">Amazon Simple Queue Service (Amazon SQS)</a> queues.</p> 
<h2>Resource management launches</h2> 
<p><a href="https://aws.amazon.com/ram/" rel="noopener noreferrer" target="_blank">AWS RAM</a> is a service that enables you to more easily and securely share AWS resources with any AWS account or within your organization. You can share <a href="https://aws.amazon.com/transit-gateway/" rel="noopener noreferrer" target="_blank">AWS Transit Gateway</a> resources, subnets, <a href="http://aws.amazon.com/license-manager" rel="noopener noreferrer" target="_blank">AWS License Manager</a> configurations, and <a href="https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/resolver-getting-started.html" rel="noopener noreferrer" target="_blank">Amazon Route 53 Resolver</a> rules with AWS RAM. For a full list, see <a href="https://docs.aws.amazon.com/ram/latest/userguide/shareable.html" rel="noopener noreferrer" target="_blank">Shareable AWS resources</a>.</p> 
<h3>AWS RAM enables sharing of Network Firewall resources</h3> 
<p><a href="https://aws.amazon.com/network-firewall" rel="noopener noreferrer" target="_blank">AWS Network Firewall</a> is a highly available, managed network firewall service for your virtual private cloud (VPC). You can create and manage firewall policies and rule groups centrally, and share them through AWS RAM within your organization. For more information, see <a href="https://docs.aws.amazon.com/network-firewall/latest/developerguide/sharing.html" rel="noopener noreferrer" target="_blank">working with shared firewall policies and rule groups</a> in the <a href="https://docs.aws.amazon.com/network-firewall/latest/developerguide/what-is-aws-network-firewall.html" rel="noopener noreferrer" target="_blank">AWS Network Firewall</a> developer guide.</p> 
<h2>Management and governance launches</h2> 
<p>AWS Identity management and governance services give you the ability to delegate administrative tasks and automate capabilities, like account creation, to make it easier to manage large, multi-account AWS environments. With AWS, you can also improve security and implement your compliance requirements by consistently enforcing who can create what type of resource and where.</p> 
<h3>AWS services with new or increased support for AWS Organizations</h3> 
<p><a href="https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/what-is-cfnstacksets.html" rel="noopener noreferrer" target="_blank">AWS CloudFormation StackSets</a> now supports designating an AWS <a href="https://aws.amazon.com/organizations/faqs/#Core_concepts" rel="noopener noreferrer" target="_blank">member account</a> to be the delegated administrator for creating and managing stack sets for your entire organization. AWS CloudFormation StackSets extends the functionality of <a href="https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/cfn-whatis-concepts.html#w2ab1b5c15b9" rel="noopener noreferrer" target="_blank">stacks</a> by enabling you to create, update, or delete stacks across multiple accounts and regions with a single operation.</p> 
<p><a href="https://aws.amazon.com/premiumsupport/technology/personal-health-dashboard/" rel="noopener noreferrer" target="_blank">AWS Personal Health Dashboard</a> now <a href="https://aws.amazon.com/about-aws/whats-new/2020/12/aws-personal-health-dashboard-supports-organization-wide-event-aggregation/" rel="noopener noreferrer" target="_blank">supports organization-wide event aggregation</a>. From a single dashboard, you have a complete view of health events, such as maintenance events, security vulnerabilities, and AWS service degradations affecting any account in your AWS organization.</p> 
<p><a href="https://aws.amazon.com/audit-manager/" rel="noopener noreferrer" target="_blank">AWS Audit Manager</a> is a new service that’s integrated with <a href="https://aws.amazon.com/organizations/" rel="noopener noreferrer" target="_blank">Organizations</a> and <a href="https://aws.amazon.com/about-aws/whats-new/2020/12/aws-announces-aws-audit-manager/" rel="noopener noreferrer" target="_blank">helps you continuously audit your AWS usage</a> to simplify how you assess risk and compliance with regulations and well-known standards.</p> 
<p><a href="https://aws.amazon.com/backup/" rel="noopener noreferrer" target="_blank">AWS Backup </a>now supports <a href="https://aws.amazon.com/about-aws/whats-new/2020/11/aws-backup-enables-aws-organizations-bring-cross-account-backup-feature/" rel="noopener noreferrer" target="_blank">cross-account backups</a> in addition to <a href="https://aws.amazon.com/about-aws/whats-new/2020/06/aws-backup-and-aws-organizations-bring-cross-account-data-protection-management-and-monitoring/" rel="noopener noreferrer" target="_blank">cross-account management</a>. You can deploy an organization-wide backup plan from the management account in your organization, ensuring backups are performed across all accounts and reducing overhead associated with managing separate backups for each account.</p> 
<p><a href="https://aws.amazon.com/blogs/aws/s3-storage-lens/" rel="noopener noreferrer" target="_blank">Amazon S3 Storage Lens</a> now provides organization-wide visibility into object storage. With the latest updates, you can now understand, analyze, and optimize storage for your entire organization, specific accounts, Regions, buckets, or prefixes, even when it consists of hundreds of accounts across multiple Regions.</p> 
<p>Finally, you can now use <a href="https://aws.amazon.com/about-aws/whats-new/2020/11/aws-trusted-advisor-enables-multi-account-reporting-of-best-practice-recommendations-with-aws-organizations/" rel="noopener noreferrer" target="_blank">Trusted Advisor</a> to generate reports with detailed check results across multiple accounts in your organization and use the <a href="http://aws.amazon.com/console" rel="noopener noreferrer" target="_blank">AWS Management Console</a> to view a high-level summary of check status.</p> 
<h3>Service Quotas now supports ABAC for quotas</h3> 
<p>With updated support for <a href="https://aws.amazon.com/about-aws/whats-new/2020/12/service-quotas-now-supports-tagging-and-attribute-based-access-control-abac/" rel="noopener noreferrer" target="_blank">tagging and attribute-based access control</a>, tags now can be applied to quotas, enabling you to easily identify, classify, or categorize applied quotas in your AWS account. Applied quotas, or account-specific quotas, are overrides that are specific to your account and that have been granted to you in the past. Additionally, you can now use these tags for <a href="https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction_attribute-based-access-control.html" rel="noopener noreferrer" target="_blank">ABAC</a>. For example, you could allow only an administrator to request increases on production quotas or quotas with high cost tagged by a different cost center.</p>
